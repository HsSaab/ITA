# CyberZ — практические работы по ИТА

Отчёты по дисциплине «Информационно-технологическая архитектура». Студент: Тыцкий Б.С., группа ИКБО-74-23. Преподаватель: Мирзоян Д.И.

## Практическая работа №2

Организационная структура, зоны ответственности, матрица владельцев и исполнителей, взаимодействие по десяти бизнес-процессам компьютерного клуба CyberZ.

- [Отчёт Word](CyberZ/ПР2_CyberZ_Тыцкий.docx)
- [Отчёт PDF](CyberZ/ПР2_CyberZ_Тыцкий.pdf)

Состав восстановлен по предоставленному образцу: методические указания к работе №2 отсутствуют.

## Практическая работа №3

Учебный прототип информационной модели: 19 сущностей, словарь данных, ER-диаграммы, связи, ограничения и план проверки с пользователями. Выполнено на основе методических указаний ПР3.pdf и отчёта по первой работе.

- [Отчёт Word](CyberZ/ПР3_CyberZ_Тыцкий.docx)
- [Отчёт PDF](CyberZ/ПР3_CyberZ_Тыцкий.pdf)

Модель не является описанием внутренней базы LanGame. Проектные допущения отмечены в отчёте; внедрение базы и интервью с сотрудниками не проводились.
